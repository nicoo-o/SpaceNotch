# Code de conduite · Code of conduct

Ce projet suit le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
(en français : [version traduite](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/)).

En bref :
- sois bienveillant et respectueux, y compris dans le désaccord ;
- pas de harcèlement, d'insulte, de propos discriminatoires, ni de publication d'informations
  privées d'autrui ;
- critique le travail, pas la personne.

Un comportement inacceptable se signale en privé au mainteneur, par l'onglet
[Security](https://github.com/nicoo-o/SpaceNotch/security/advisories/new) ou par son profil GitHub
[@nicoo-o](https://github.com/nicoo-o). Tout signalement est traité avec discrétion.

---

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind and respectful, including when you disagree; no harassment, insults, discrimination
or sharing others' private information; criticise the work, not the person. Report unacceptable
behaviour privately to the maintainer ([@nicoo-o](https://github.com/nicoo-o)).
