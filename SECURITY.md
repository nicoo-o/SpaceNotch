# Sécurité · Security

**Signaler une faille en privé.** N'ouvre pas de ticket public. Utilise le bouton **Report a
vulnerability** de l'onglet [Security](https://github.com/nicoo-o/SpaceNotch/security/advisories/new) :
seul le mainteneur le verra.

Dis ce que tu as trouvé, comment le reproduire, et la version touchée (Réglages › À propos). Une
réponse arrive en général sous quelques jours. Le correctif est publié dans une nouvelle version, et le
signalement est rendu public ensuite, avec ton accord pour te citer.

Versions suivies : la dernière version publiée.

---

**Report a vulnerability privately.** Please don't open a public issue. Use **Report a
vulnerability** in the [Security](https://github.com/nicoo-o/SpaceNotch/security/advisories/new) tab:
only the maintainer will see it.

Tell what you found, how to reproduce it, and the affected version (Settings › About). Expect an answer
within a few days. The fix ships in a new release, and the advisory is published afterwards, crediting
you if you wish.

Supported versions: the latest release.
